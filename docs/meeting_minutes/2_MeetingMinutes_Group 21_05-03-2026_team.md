### **Discussion**
The client introduced the background of the project and explained the importance of protecting cultural heritage sites from bushfire risks. Currently, there is no existing tool that integrates cultural heritage information with fire management systems.

The main goal of the project is to develop a tool that helps land managers identify areas where cultural heritage sites may be vulnerable to fire. The system may visualize fire vulnerability using a simple classification such as low, medium, and high risk.

The client suggested that the system could potentially include two components. The first component is a **web-based platform** that displays heritage sites and fire vulnerability levels on a map. This platform should allow users to easily identify high-risk areas. The second optional component is a mobile tool for field use, allowing rangers to **record heritage sites** by capturing GPS coordinates and photos.

The project should consider several environmental factors that influence fire behaviour, including topography, vegetation, and wind conditions. These factors can help estimate the intensity of fire in different areas.

Different types of heritage sites may also have different levels of vulnerability. For example, stone tools are generally resistant to fire, while wooden structures, rock paintings, and paper bark artifacts may be highly vulnerable.

Students raised several questions during the meeting, including:
1.	Do we need to design our own method to calculate fire vulnerability based on environmental factors?  
    - Answer: Yes. There is currently no established model, so each team should develop its own simplified approach.

2.	Does the system need to support offline usage in remote areas with poor internet signals?
    - Answer: Ideally yes. Data can be stored locally and uploaded once internet connection becomes available.

3.	How should fire vulnerability be defined in the system?
    - Answer: It should be based on factors such as topography, vegetation, and wind, which influence fire intensity.

4.	Does the type of heritage site affect fire vulnerability?
    - Answer: Yes. Different types of heritage have different vulnerability levels (e.g., stone tools are more resistant than wooden structures).

5.	Should the system allow users to input or update fire-related data?
    - Answer: At minimum, the system should display current fire vulnerability levels. Additional updating features are optional.

6.	How large should the study area be for the project?
    - Answer: A manageable area should be chosen, ideally several hundred to a few thousand square kilometres.

7.	Is the goal to eventually apply this system to the whole of Australia?
    - Answer: Possibly in the future, but this project should focus on a smaller test area.

8.	Why are coordinates and photos required when recording heritage sites in the field?
    - Answer: Coordinates identify the site location, while photos help determine the type and condition of the heritage.

The client also suggested that each group should select a manageable geographic area for analysis rather than attempting to cover the entire state. The selected area should ideally include different types of landscapes, such as coastal areas, plains, or hills, so that the model can be tested under different environmental conditions.

Possible data sources for the project include the Aboriginal Cultural Heritage Inquiry System (ACHIS) and the InHerit heritage database, which provide information about registered heritage sites.

### **Agreed Task**

- Explore possible mapping or GIS tools for visualizing heritage sites and fire risk.
